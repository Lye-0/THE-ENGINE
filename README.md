# FERRO — Engine Observatory

**Power. Revealed.**

金属の反射と、内部機構の連動を鑑賞するインタラクティブな3Dエンジン展示です。オリジナルの直列4気筒・DOHC・16バルブを、外観／断面／分解の3つの見せ方で観察できます。

モデルも描画処理も、このプロジェクトのJavaScriptから生成します。**外部CDN、3Dモデル、画像テクスチャ、Webフォント、APIキー、パッケージのダウンロードは不要です。** 本体は単一HTMLではなく、HTML・CSS・JavaScriptを分離しています。

## 起動

ZIPを展開して、このREADMEと同じフォルダーで実行します。ローカルサーバーと自動テストにはNode.js 20以上を使います。

```powershell
npm start
```

ブラウザーで **http://127.0.0.1:4173** を開いてください。`npm install` やビルドは必要ありません。停止はターミナルで `Ctrl+C` です。

別のポートを使う場合:

```powershell
npm start -- --port 5173
```

本体は相対パスの通常のスクリプトで構成され、`fetch` を使用しません。通常は `index.html` を直接ブラウザーで開くこともできますが、ファイルビューアーやブラウザーの制限がある場合は上記のローカルサーバーを利用してください。スマートフォンのファイルプレビュー画面では、WebGLやJavaScriptが実行されないことがあります。

## 操作

| 操作 | 動作 |
| --- | --- |
| ドラッグ／1本指スワイプ | エンジンを中心にカメラを回転 |
| ホイール／2本指ピンチ | 拡大・縮小 |
| 右ドラッグ／Shift＋ドラッグ／2本指移動 | 視点の平行移動 |
| 外観・断面・分解 | 外装、可動機構、部品の位置関係を切り替え |
| 再生ボタン | 再生・一時停止 |
| ENGINE SPEED | 800～6,000 rpmを設定 |
| PLAYBACK SPEED | 1/80、1/40、1/10、実時間から鑑賞速度を選択 |
| CRANK ANGLE | 720°のサイクルを手動で観察。操作すると一時停止 |
| 構造を探索する | 部品の位置に連動するマーカーと日本語の説明 |
| 燃焼を可視化 | 行程を色で示す補助表示のオン・オフ |
| 右側の軌道／戻るアイコン | カメラの自動回転／視点リセット |
| 右上の星 | 標準→高品質→軽量の順で描画品質を変更 |
| 右上のスピーカー | 合成エンジン音のオン・オフ |
| 右上の情報アイコン | 操作方法と展示の説明 |

カメラ用キャンバスにフォーカスがあるときは矢印キーでも回転できます。ボタンや入力欄を操作中でなければ、`Space` は再生／停止、`1`・`2`・`3` は表示モード、`R` は視点リセット、`E` は部品解説です。`Esc` で解説パネルまたはダイアログを閉じます。

初期状態は**断面・標準品質・1,200 rpm・1/40倍速・音なし**です。動きを抑えるOS設定がある場合は一時停止で開始します。スローモーションは観察用の時間倍率であり、表示RPMとは分けて扱っています。クランク角の720°は0°と同じ状態に戻ります。

音は実録ではなく、回転数に応じたWeb Audioの合成音です。スピーカーボタンを押してから、エンジンを再生すると鳴ります。再生停止やタブ非表示時には音量を落とします。音の回転数は表示RPMに従い、鑑賞用スローモーションには追従させていません。

## 表現と機構

- ピストン／ピストンリング／ピン、I字断面のコンロッド、クランクの偏心部とカウンターウェイト、フライホイールを独立した形状として構築。
- 2本のカムシャフト、16個のカム、16本のバルブと圧縮するスプリング、タイミングチェーンとスプロケットを構築。
- 1–3–4–2の点火順序。ピストン位置はコンロッド長を含むスライダークランクの幾何式で算出。コンロッドの両端はピストンピンとクランクピンの位置に一致。
- カムはクランクの1/2の角速度。バルブとカム形状は同じ行程・リフト関数から生成。
- GGX型の金属反射、解析的なスタジオ光源の映り込み、シャドウマップ、画面空間の陰影、マルチサンプルアンチエイリアスを組み合わせた独自WebGL2描画。
- ベベル、切断面の縁、鋳肌、切削方向の粗さ、異なる金属色を部品ごとに設定。
- 停止中は視点・表示が変化しない限り同じGPUフレームを描き続けないようにしています。

## 展示モデルとしての範囲

実在メーカーのエンジンをスキャンしたCADデータではありません。2.0 L／86 × 86 mmはこのオリジナル展示の設定であり、全ての形状が製作用寸法に適合するという意味ではありません。

往復・回転機構は幾何的に連動しますが、実機の弾性、振動、摩擦、潤滑、熱、圧力、流体、負荷変動を解く物理シミュレーターではありません。バルブの開閉はオーバーラップや進角を省いた理想化した4行程です。チェーンの接触・張力、外装の内部流路、ガスケット、周辺補機なども展示向けに簡略化しています。

断面は外装の表示・非表示と半割り形状の組み合わせで、任意の切断平面を動かすCAD断面機能ではありません。分解モードは組み立ての関係を観察する演出です。部品を離したまま機構を動かすため、実機がその状態で運転できることを示していません。軸間が離れる分解表示では、チェーンを非表示にします。燃焼色は行程を示す視覚的補助であり、実際の燃焼映像や流体解析結果ではありません。

## テスト

```powershell
npm test
```

Node.jsの標準テストランナーのみを使用します。機構の整合性、実モデルのコンロッド端点、頂点データ、モード遷移、静的サーバー、相対参照、プレビュー生成を検証します。

ブラウザーによる操作確認の環境・範囲・制約は `docs/VERIFICATION.md` に記載しています。スマートフォン／タブレットの画面サイズでレイアウトを確認していますが、個別のiPhoneやiPad実機の性能を保証するものではありません。

## 公開・プレビュー用のファイル

一般的な静的ホスティングには、`index.html`、`favicon.svg`、`css/`、`js/` の位置関係を保って配置します。サーバー側APIやビルドは不要です。テストや開発用サーバーを公開環境で動かす必要はありません。

チャットで受け渡すための、自己完結したHTMLプレビューを別途生成する場合:

```powershell
npm run preview:build
```

`preview/FERRO-preview.html` が生成されます。**これは配布・確認用の副生成物です。本体は引き続き分離したファイル構成です。**

## 動かない・重いとき

WebGL2を利用できない環境では、画面に開始できない理由を表示します。まず通常のブラウザーで開き、端末やブラウザーの3D描画が無効になっていないか確認してください。ファイルビューアーで開いている場合は、静的サーバーでの表示を試してください。

重い場合は右上の星を押して **LOW** にしてください。初期設定はスマートフォンでも **STD** です。HIGHは高解像度と影の品質を優先するため、端末によっては重くなります。視点が分からなくなった場合は右側のリセットを押します。
